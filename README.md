# 产品定价 Skill

版本：0.1.0 独立用户版。将价值、支付条件、交付责任和实际成本接成可讨论的报价建议。沿用韩叙产品方法，使用你自己的事实，不带入作者的产品、客户、价格和权益。

## 适用与边界

适合已有具体产品，需要定价或校准报价的人。一次可以只处理本项，不强制跑完整商业模式或四个Skill。人群、问题或产品方向仍不清时只补会改变判断的缺口，不替你编造需求。建议、实际制造、客户采用与经营效果分别记录，不自动改价、联系客户、上架或发布。

## 准备哪些材料、怎样写

必需材料：计价单位、具体交付、当前价、客户支付信息、总占用、现金成本及现有承诺。可以直接在对话提供，也可放在自己的工作目录，不要求固定文件名。写具体对象、时间与计量单位，区分已确认事实、已售承诺、拟议调整、测算假设及未知。
可选：现有方案、真实反馈、报价或可用母版。已经有的有效材料继续使用；缺少会改变判断的信息才补问，不凭空填成0或既有成果。

完整合成示例（仅练习，不代表真实客户或效果）：

```text
用 $hanxu-product-pricing：
一份单客四周诊断服务的候选价为1000元。四周总时间40小时、已有占用12小时、预留4小时、共用准备4小时，每客新增4小时，准备接5客。每客直接现金成本100元，这期固定支出200元，渠道费10%。若计算本人劳动价值，按每小时50元假设。没有实际付款证据，也没有市场价资料。请复算现金差额与产能，再给报价建议，不称净利润、不把测试价改成已售价格。
```

## 安装和使用

取得完整 `hanxu-product-pricing` 文件夹后，交给能读取Skill的AI助手安装，保留配套文件。旧版与本地修改先备份到技能发现目录外，不覆盖用户任务资料。让助手读回名称、0.1.0版本和实际位置，未识别按宿主说明恢复。

安装后发送 `$hanxu-product-pricing` 和自己的材料。只处理本次要求的范围；局部返修说清改哪里、保留什么。已有有效资料不重填。结果和记录放自己的工作目录，不放安装目录。

## 包里有什么

| 文件 | 用途 | 要修改吗 |
|---|---|---|
| `SKILL.md` | 本项具体方法和工作边界 | 通常不用 |
| `references/acceptance.md` | 对照实际结果检查 | 通常不用 |
| `scripts/calculate_product_capacity.py` | 可选的同周期产能与现金情景复算 | 通常不用 |
| `examples/capacity.json` | 可运行的合成数值输入，明确单位和假设 | 复制到自己的目录改 |
| `agents/openai.yaml` | 技能发现信息 | 通常不用 |
| `README.md`、`VERSION`、`SKILL-MANIFEST.json` | 说明、版本和文件校验 | 通常不用 |

## 会得到什么

主报价或测试区间、计价单位与范围、现金和时间情景、关键假设及最小验证。交付应能直接帮助你做决定，关键判断能回到材料，具体范围与已有承诺一致；缺口与假设就近说明，不以填满表格当成解决问题。

可选复算：在解压后的技能目录运行 `python3 scripts/calculate_product_capacity.py examples/capacity.json`。只做明确单位与周期的算术，未知值不自动当0；日历峰值、需求和实际交付质量仍须另查。直接现金差额和本人劳动价值分开，未列成本不隐瞒，结果不称净利润。


## 依赖、费用、验证与许可

需要可读完整Skill的AI助手及有权使用的材料，基础判断不需平台登录或额外API密钥。可选算术脚本需要Python 3.9以上且只用标准库。模型及工具费用按自己的服务承担，不自动购买。材料由选择的AI服务处理，不自动发送客户或传入其他平台。

本版实际验证范围见 VALIDATION.md；文件检查、合成演练、真实采用和商业效果分开，不承诺普遍稳定或成交。反馈提供版本、去敏材料、具体不合理的判断，不需凭据或客户档案。

没有擅自新增开源许可证；公开可下载与再分发/转售权利分别核实。
